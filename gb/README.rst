GB550D
======

:Author: Magic Lantern contributors
:License: GPL-2.0
:Summary: Game Boy / Game Boy Color module for Canon EOS 6D.

Place legally obtained ``.gb`` / ``.gbc`` ROMs in ``ML/GB/``. The module
lists at most 32 ROMs alphabetically and runs them through the Walnut-CGB core.

Controls
--------

* Arrows: D-pad
* SET: A
* PLAY: B
* Hold magnify: B
* INFO: Select
* MENU: Start
* Q: exit

The 6D build is selected with ``GB_6D=1``.
